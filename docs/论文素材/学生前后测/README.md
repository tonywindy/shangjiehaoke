# 学生前后测图片使用说明

## 一、处理原则

- 原始照片保持不变，所有处理结果均为副本。
- 正文图只裁取与论证有关的题目区域，不呈现学生姓名和班级。
- 附录整页使用“学生A—D”匿名编码，并遮盖姓名、班级等个人信息。
- 仅进行了裁切、排版和匿名化处理，没有修改题目、学生笔迹、算式或答案。

## 二、正文建议使用的图片

### 1. 学生A：周长概念理解的前后变化

文件：`figure_student_A_concept_pre_post.png`

建议图题：

> 图X 学生A“周长与面积辨析”前后测作答对比

适合放置位置：

- 第三章“第一阶：智能诊断”中，说明AI如何从学生作品中识别“把内部涂色误认为周长”的概念混淆。
- 第三章“第三阶：多维评学”或学习效果分析中，呈现学生由混淆“边界—内部”到能够正确区分周长和面积的变化。

论证重点：

- 前测中，学生A能完成长方形四边长度与周长计算，但在表示周长的选择、描画任务中出现错误。
- 这表明其主要困难并非一般计算能力不足，而是“封闭图形一周长度”的表象尚未稳定建立。
- 后测中，学生能够在生活情境和图形情境中正确辨认周长，说明概念表象得到改善。

### 2. 学生C：由面积算法误用到周长公式正确应用

文件：`figure_student_C_formula_pre_post.png`

建议图题：

> 图X 学生C“长方形周长计算”前后测作答对比

适合放置位置：

- 第三章“第二阶：动态分层”中的学生画像分析。
- 第三章“精准干预”后的学习效果分析。

论证重点：

- 前测中，学生C使用“8×5=40（平方厘米）”，将面积算法迁移到周长问题。
- 后测中，学生能够使用“（9+4）×2=26（厘米）”求长方形周长。
- 这一变化可用于说明学生从“算法混用”转向“依据周长意义选择运算关系”。

### 3. 学生D：组合图形边界判断的参考性变化

文件：`figure_student_D_boundary_reference.png`

建议图题：

> 图X 学生D组合图形与靠墙围篱问题的作答对比（参考）

适合放置位置：

- 第三章“反馈迭代”中，用作边界意识发展的个案补充。
- 不建议将其作为严格的同质前后测效果证据。

使用限制：

- 前测题考查两个正方形拼成长方形后的公共边是否计入外周长。
- 后测题考查靠墙围篱时不需要计算靠墙一边。
- 两题都涉及“确定实际需要计算的边界”，但情境和认知要求并不完全相同。
- 如需形成严格的前后对照，建议补充一道与前测同结构的“拼接图形公共边”后测题。

## 五、写入论文前仍需补充的证据

若论文需要较有说服力地说明“三阶六步”模式的实施效果，建议继续补充：

1. 与学生A或学生C相对应的AI初步诊断、教师确认记录。
2. AI根据错因和学生画像生成的三阶梯干预题。
3. 学生完成干预题的过程性作品或课堂观察记录。
4. 学生D同结构的“拼接图形公共边”后测题。
5. 班级人数、前后测时间、评分规则及全班各题正确率。
6. 如需公开发表，应继续核对图片中是否存在校名、学号等其他可识别信息。
