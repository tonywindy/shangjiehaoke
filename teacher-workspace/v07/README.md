# 教师工作台 v0.8 · 本地试用版

这个目录在 v0.7 知识矩阵闭环上增加真实班级使用入口：

1. 班级导航进入原班级主页；点击“编辑座位”后进入编排模式，可导入名单并整体移动座位。
2. 在矩阵中记录“未判断 / 已掌握 / 待提升”。
3. 按单元自动积累和复用常用错因。
4. 在班级主页的座位表上点击学生姓名，用两种课堂打点方式批量更新全班状态。
5. 在班级主页的座位表直接登记作业的已完成、部分完成与未完成。
6. 复制不含学生姓名的 Prompt，把生成结果按知识点保存到题库。

## 数据边界

- 数据使用 IndexedDB 保存在当前浏览器中。
- 不上传学生数据，不调用任何 AI 或第三方接口。
- 班级的座位编辑页面可导出和恢复 JSON 备份。
- 这是单班级、本机试用版本，不适合作为唯一数据副本。

## 对 v0.7 数据模型的一处实现说明

产品界面中的“未判断”仍不作为业务状态统计。为了同时满足“历史只追加”和
“状态可从待提升切回未判断”，实现层使用 `cleared` 事件作为撤销标记；读取当前状态时，
最新事件为 `cleared` 等价于没有当前判断。后续服务端数据模型应显式保留这一类撤销事件，
否则“只追加”和“三态循环”无法同时成立。
