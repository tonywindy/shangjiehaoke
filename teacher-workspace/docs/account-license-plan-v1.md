# 教师工作台账号与授权方案 v2

## 已上线架构

- 前端：`shangjiehaoke.com/teacher-workspace/`
- 授权接口：Cloudflare Worker 的 `/api/workspace/*`
- 授权数据库：独立 Cloudflare D1 `shangjiehaoke-workspace-auth-db`
- 原 AI 教学数据库继续使用 `DB`；授权数据库使用 `AUTH_DB`，两者不混表。
- 学生、座位、课堂、作业和学情仍保存在教师当前浏览器的 IndexedDB，不进入 D1。

## 注册和续费

1. 管理员在后台生成一次性授权码，完整号码仅在生成当次显示。
2. 新用户填写用户名、密码、授权码并同意使用协议。
3. Worker 在 D1 事务中领取授权码、创建账号并记录协议版本；并发使用同一码时只有一个账号能成功。
4. 已有账号在账号页兑换新授权码续费。限时授权从“当前到期时间与当前时间中较晚者”继续顺延；长期授权无需续费。
5. 撤销已兑换授权或停用账号会删除现有会话；已打开的工作台也会定时和重新聚焦时复核。

## 密码与会话

- 密码不明文保存。普通账号使用“每用户随机盐 + Cloudflare Secret 中独立密码保护密钥”的 HMAC 摘要。
- 初始管理员密码只通过 Cloudflare Secret 引导创建，不写入代码、配置或 GitHub。
- 管理员首次登录必须修改初始密码。
- 管理员可以给普通用户设置一次性临时密码；旧会话立即退出，用户下次登录必须改密。
- 会话令牌只在浏览器的 `HttpOnly`、`Secure` Cookie 中保存，D1 只保存不可逆摘要。

## 云端数据

D1 保存：

- 用户名、密码摘要、账号状态；
- 授权码摘要、前缀、状态、期限和兑换关系；
- 登录会话摘要；
- 协议同意版本和必要的安全/管理审计记录；
- 接口限流计数。

D1 不保存：

- 学生姓名和名单；
- 班级、座位、课堂打点；
- 作业、补交、任务、学情、错因和题库。

## 本机数据隔离

- 授权版 IndexedDB 按云端 `user.id` 命名。同一浏览器登录两个教师账号时，二者不能看到对方的本机学生数据。
- 旧版未分账号的本机数据库只允许第一个确认归属的授权账号迁移，避免后续账号重复复制。
- 未登录用户使用独立体验数据库；授权失效或授权服务不可达时使用阻断页，不会静默打开体验数据造成“数据丢失”错觉。
- 换电脑、换浏览器、清除网站数据或重装系统不会自动恢复教学数据，必须先导出备份再恢复。

## 第一版暂不提供

- 短信/邮箱验证码；
- 自动支付；
- 教学数据云同步；
- 自助找回密码；
- 设备数量限制。

忘记密码先走私信核验和管理员人工重置。用户量明显增加后，再增加邮箱验证、自助找回和自动支付。
